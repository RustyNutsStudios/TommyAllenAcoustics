>> COMMON PROBLEMS

► The first sound takes ages to play, or I have to click twice
Fixed. Update to the latest version. The editor tab used to create its audio device in a suspended state and never wake it, so the first shot was scheduled silently and arrived late — and everything queued behind it fired at once. If you are still seeing it after updating, tell me your engine version.
► SEND TO UNREAL does nothing / no assets appear
The import step needs the Python Editor Script Plugin. It ships with Unreal and is normally on by default, but check Edit > Plugins and search for Python. Enable it, restart the editor, try again.
► I cannot find the launcher asset in the Content Browser
Plugin content is hidden by default. In the Content Browser open Settings and tick Show Plugin Content. The toolbar button and the Tools > Tommy Allen Acoustics menu work whether you do this or not.
► Where did my sounds go?
Into your open project under /Game/TAA/<Tool>/<YourName>/ — the SoundWaves, a plain SoundCue and a MetaSound Source. If you used DOWNLOAD instead, raw WAVs land in your project's Saved/ folder and the tool prints the exact path.
► The plugin will not enable after install
Each engine version has its own build. Make sure the one you installed matches the engine you are opening — 5.6, 5.7 and 5.8 are separate downloads. Windows editor only.
► Do I have to wire up the ammo count?
Only for the ammo-aware assets, and it is two Blueprint nodes on the weapon's Audio Component: Set Int Parameter "AmmoCount", then Set Trigger Parameter "Fire". If you never wire it, nothing breaks — AmmoCount defaults to mid-magazine and you get an ordinary shot.

>> REPORTING A BUG

Send these and I can usually find it without a back-and-forth:

  • Which tool, and the version number
  • Engine version — 5.6, 5.7 or 5.8
  • What you did, in the order you did it
  • What happened, and what you expected instead
  • Anything red in the Output Log (Window > Output Log)
  • A screenshot if it is a visual thing, a short clip if it is an audio thing

Feature requests are welcome too. A lot of what is in these tools got there because someone asked.
