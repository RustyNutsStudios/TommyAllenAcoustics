>> WHAT IT DOES

Drop a WAV into each of the four slots — or a whole set per slot. Set how far each layer is allowed to move: timing, pitch, level, tone. Turn VARIATION up. Press BOUNCE, then audition the takes: keep the good ones, re-roll the rest, download the set as WAVs in a zip.

The variation that actually fools the ear is timing between layers. Doing that at runtime costs you on every playback, forever. Bake it at design time and it costs nothing.

>> WHAT YOU GET

  • Four layer slots — each takes one file or a whole set, so four slots of five files is 625 combinations to pick from.
  • Per-layer ranges — timing jitter, pitch, gain, tone. Ranges stay musical at 100.
  • The VARIATION knob — one control, 0 to 100, scaling every range at once.
  • Audition loop — play each take, keep it or cull it, re-roll what you culled. Nothing reaches your project un-heard.
  • Seeded — same seed, same set, every time. Presets reload identical.
  • WAV and zip export — N finished files, named, ready for the Content Browser.
  • Royalty free — what you bounce is yours.

>> THE TECHNICAL BIT

Runs in your browser. Your files never leave your machine — nothing is uploaded, there is no account.

Deterministic. A seed names every set. Same seed, same files, same takes — so a preset recalls exactly.

Why bake it? Layered at runtime, you pay the layering cost on every playback, forever. Baked, you pay once, at design time.
