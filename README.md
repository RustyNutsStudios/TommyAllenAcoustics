# Tommy Allen Acoustics

Sound tools for Unreal Engine, free to use in your browser —
**https://tommyallenacoustics.com**

This repo is the site and the free browser versions of the tools:
Audio Utilities (Mini Recorder, Mini DAW, Variation Designer), Shot Forge,
Sci Forge, Click Factory, Impact Forge and friends.

The Unreal Editor plugins are the commercial versions, on Fab:

- Shot Forge — https://www.fab.com/listings/4419cb9b-cd75-4248-b9d0-c4205ba10eab
- Sci Forge — https://www.fab.com/listings/19fb0cbe-b8b9-4ad2-92b2-202549f1e5b2
- Click Factory — https://www.fab.com/listings/2264595c-03d7-4bcc-bbb8-f7aaf752d14f
